# SCAT Practice

Adaptive short-form SCAT practice for Krish, Arya, and Kira.
- App: `site/` (GitHub Pages). Banks: `site/data/*.json`.
- Verify a bank: `uv run python tools/audit_bank.py site/data/advanced.json`
- Tests: `uv run pytest && node --test tests/calibration.test.mjs`
- New questions are generated by `.github/workflows/generate.yml` and verified before commit.
- Webhook setup: `apps-script/SETUP.md`. Design: `docs/superpowers/specs/`.

## Live site
https://meninder.github.io/scat-practice/site/ — PIN-gated; profiles for Krish, Arya, Kira.
Completion emails go to the parent via Apps Script (`apps-script/SETUP.md`); low banks refill
themselves via `.github/workflows/generate.yml` (author → blind-verify → audit → commit).
